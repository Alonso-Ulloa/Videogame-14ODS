# Investigación de SRS y selección de plantilla

## Resumen (menos de una cuartilla)
Una SRS establece qué debe hacer el software y cómo comprobar su aceptación. Distingue funciones de atributos de calidad y restricciones; permite acordar alcance y relacionar cada necesidad con pruebas y tareas. En este videojuego, “comer incrementa crecimiento” es funcional, mientras que una carga máxima de cinco segundos es un requisito de rendimiento.

IEEE 830-1998 presenta recomendaciones y esquemas para especificaciones, pero está sustituida por ISO/IEC/IEEE 29148:2011 (IEEE, 1998). El catálogo de ISO identifica 29148:2018, segunda edición, como publicada y confirmada en 2024, con revisión en desarrollo (ISO, 2018). Por ello, IEEE 830 sirve como antecedente de estructura, no como norma vigente. Se consultaron fichas públicas; no se leyó ni se afirma conformidad con el texto íntegro de pago de ISO.

NASA recomienda requisitos claros, identificables, consistentes, factibles y verificables, expresados como obligaciones del producto y acompañados de supuestos explícitos (NASA, s. f.). Para aplicarlo, cada ficha tendrá ID, título, descripción, prioridad y criterio de aceptación. “Respuesta rápida” se reemplaza por una condición medible y su entorno de prueba. La validación confirma que se pidió lo correcto; la verificación comprueba el producto contra lo especificado.

Se elige una plantilla académica adaptada: **1. Introducción; 2. Descripción general; 3. Requerimientos**, con glosario, restricciones, supuestos, fichas y checklist. Su tamaño facilita la revisión de un equipo de dos personas y conserva la trazabilidad de los 40 RF y 20 RNF originales. No se presenta como reproducción ni certificación de una norma. GitHub Projects permite representar las mismas Issues en tabla, tablero y roadmap, con campos personalizados (GitHub, s. f.). Se usarán semanas relativas mientras se aclaran las fechas contradictorias del Excel.

El 12/11/2026 se abrieron las cuatro fuentes oficiales anteriores, se contrastó el estado de las normas y se compararon los IDs con el PDF proporcionado.
